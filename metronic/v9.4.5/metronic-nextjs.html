Introduction

A guide to understanding and utilizing the Metronic Next.js Boilerplate.

Welcome to Metronic Next.js Documentation!

A fully functional React app with a modern UI, built with Next.js and Tailwind CSS, featuring a comprehensive component library, multiple dashboard layouts, and server-side rendering capabilities.

What is Metronic Next.js?

Metronic Next.js is a powerful React dashboard framework designed to help developers and businesses by:

  • Providing a complete set of UI components based on Radix UI primitives with Tailwind CSS styling
  • Supporting multiple dashboard layouts and themes for different use cases
  • Delivering excellent performance through Next.js App Router and server components
  • Offering a scalable architecture for building complex admin interfaces and applications
  • Providing enterprise-grade features like authentication, internationalization, and comprehensive error handling

Key Features

  • Next.js 15.3: Utilize the latest App Router architecture with server components and client components
  • React 19: Build dynamic and reactive user interfaces with the latest React features
  • TypeScript: Ensure type safety and improve developer experience
  • Tailwind CSS 4: Rapidly design and customize responsive UIs with the latest version
  • Radix UI: Leverage unstyled, accessible UI primitives for maximum flexibility
  • ReUI Components: Benefit from our open-source React component library built on Radix UI
  • Multiple Layouts: Choose from 10 pre-built dashboard layouts (Demo1-Demo10)
  • Authentication: Implement secure user authentication with next-auth
  • App Router: Modern, file-system based routing with nested layouts
  • Internationalization: Support multiple languages with i18next
  • Custom Hooks: Benefit from pre-built React hooks for common functionality
  • State Management: Manage application state efficiently with React Context API
  • Provider System: Leverage a flexible provider architecture for global features
  • Dark Mode: Toggle between light and dark themes with next-themes
  • RTL Support: Full support for right-to-left languages
  • Prisma ORM: Type-safe database access and migrations

Why Choose Metronic Next.js?

  • Modern Stack: Built with the latest technologies for optimal developer experience
  • Performance: Optimized for speed and efficiency with Next.js server components
  • Flexibility: Adaptable for various admin and dashboard applications
  • Comprehensive: All the components and tools you need for building complex interfaces
  • Maintainable: Well-structured code and detailed documentation for long-term maintenance
  • Production-Ready: Deploy with confidence using our simplified deployment guides
