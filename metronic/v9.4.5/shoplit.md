# Introduction

A guide to understanding and utilizing the Shoplit Boilerplate.

## Welcome to Shoplit Documentation!

A fully functional Next.js app for managing e-commerce,
featuring complete database integration with Prisma and PostgreSQL.

## What is Shoplit?

Shoplit is a versatile framework designed to empower businesses and developers by:

- Built with ReUI, the fastest-growing free React library that offers robust CRUD modules and beautiful UI components.

- Supporting easy customization with flexible design and functionality integration.

- Delivering top-tier performance and SEO optimization.

- Providing scalability through server-rendered, client-side, or hybrid applications.

- Offering a foundation for diverse applications, including CRMs, ERPs, and beyond, making it an excellent starting point for modern web apps.

## Key Features

- Next.js Integration: Combine server-side rendering, static site generation, and client-side rendering for optimal performance.

- React: Develop interactive, reusable, and component-driven user interfaces.

- Tailwind CSS: Quickly design sleek, responsive UIs.

- TanStack Query & Table: Efficiently handle server-side state management and advanced data tables.

- Prisma OR: Simplify database management with intuitive modeling and querying.

- Zod: Ensure runtime validation with a powerful TypeScript schema tool.

- React Hook Form: Simplify form management and validation.

- Radix UI: Use unstyled UI primitives for maximum design flexibility.

- Dark Mode Support: Deliver an enhanced experience with easy theme toggling.

- RTL (Right-to-Left) Support: Full accessibility for right-to-left languages.

- i18n (Internationalization): Easily implement multilingual capabilities for global reach.

## Why Choose Shoplit?

- Efficiency: Streamlined workflows and developer tools accelerate your project timeline.

- Flexibility: Perfectly adaptable for businesses of any size and across industries.

- Performance: Engineered to meet modern web application standards with exceptional speed and reliability.

- Community and Support: Backed by an active developer community and detailed documentation to guide you every step of the way.
