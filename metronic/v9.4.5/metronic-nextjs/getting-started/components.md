# UI foundation

Metronic React is powered by ReUI, our open-source React component library by KeenThemes. ReUI provides a comprehensive set of accessible, unstyled, and customizable UI primitives that form the foundation of all Metronic components and layouts.

- Accessible & Unstyled: Build your own design system or use the provided styles.

- Radix UI Primitives: Leverage the accessibility and flexibility of Radix UI.

- Tailwind CSS Integration: Easily style components with utility classes.

- Production Ready: Used in all Metronic dashboards and layouts.

To explore the full list of available components, usage examples, and advanced customization, visit the ReUI documentation.
